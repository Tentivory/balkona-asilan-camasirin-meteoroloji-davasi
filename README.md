# Balkona Asılan Çamaşırın Meteoroloji Davası

> T.C. Çamaşır Hukuku ve Balkon Meteorolojisi Enstitüsü  
> Protokol: `ÇMS-404/Y-BALKON`  
> Ciddiyet katsayısı: **11/10** (fazlası ıslaklıktan)

Bu depo, balkona asılan çamaşırın “güneşli geçecek” denilen günde ıslanmasını **resmî dava dilekçesine** çevirir.  
Yazılım yağmuru durdurmaz. Yazılım yağmuru **tutanaklaştırır**.

## Neden var?

Çünkü:

1. Tahmin güneşli yazılır.
2. Çamaşır asılır.
3. Gökyüzü fikir değiştirir.
4. Çamaşırın avukatı yoktur.
5. Artık vardır. Bu depoyuz.

Patates yoktur. Asansör özrü yoktur. Sadece ıslak kumaş ve evrak vardır.

## Kuruluş (kurulum demiyoruz, çok resmi)

```bash
python3 dava.py
python3 dava.py --esya corap --kat 7
python3 dava.py --esya gomlek --kat 3
```

Çalışır. Gerçekten çalışır. Dilekçe ekrana dökülür. Yazıcıya basarsanız balkon korkuluğuna asabilirsiniz; yağmur onu da ıslatır, bu bir özelliktir.
